# Reproduction procedures and limits

This publication preparation performed static checks. No simulation, numerical analysis or public-script execution was performed. Saved outputs were generated by the archived sources.

## Archived environment

Windows 11, Python 3.13.17 and NumPy 2.5.4 were recorded for both studies. The oscillator also records Matplotlib 3.11.2. The oscillator requirements specify dependency lower bounds, so they do not pin that complete environment. Availability of these recorded versions has not been tested here.

## Commands for a future reproduction

Run from `toy_oscillator/`, in an environment with its requirements installed.

```powershell
python -B src/run_plateau_study.py --out run_repeat
```

Run from `synthetic_agent/`, with NumPy installed.

```powershell
python -B run_pilot.py --out run_repeat
```

Use a new output directory. These commands were not run in this phase. The surrogate archive data came from the archived script. The publication variant removes only manuscript-text generation and its JSON write. Source hashes are distinguished in the [derived manifest](../synthetic_agent/run/manifest.json). A future runtime manifest is freshly generated by the script and differs from this archival derivative.

## Timing and design

The oscillator uses dt = 0.025, seeds 7, 11, 19 and plateau durations 18, 36, 72, 144. R_mean is evaluated at t - dt, while H_mean and R_global are at t. Late-window calculation follows the pre-step R_mean sampling time. See the [original manifest](../toy_oscillator/run/results/manifest.json) for integration and area definitions.

The surrogate uses 1,000 matched trials, nine agents, 16 rounds and correction from round 7. Truth, signs, broadcasts and tie votes are shared across arms. Post-correction averages cover rounds 7–16, with 2,000 paired trial-level bootstrap resamples.

The [verification record](VERIFICATION.md) transcribes archived comparisons with absolute tolerance 1e-8, including maximum differences and PNG byte equality. A present integrity match does not establish a new successful reproduction.
