# Provenance

The conceptual basis is the author's canonical research draft dated 2026-11-08. The completed v0.3 study and its archived outputs supply numerical evidence. Submission status is author-reported.

The inertial oscillator v0.2 kernel predates the v0.3 evaluation. Its byte-identical copy is [inertial_swarm_v02.py](../toy_oscillator/src/inertial_swarm_v02.py). v0.3 adds plateau-duration evaluation and the separate programmed-surrogate study.

The 18 unchanged publication files were checked against the Phase 2 audit by size and SHA-256. Summary tables are transcriptions of previously reported aggregates. Run CSVs, JSONL and figures are saved outputs from archived executions. This preparation performed no experimental runs or numerical regeneration.

The surrogate publication script removes the manuscript-text function and its JSON write. Static AST comparison confirms that the rest of the original syntax tree is preserved.
